# ScreenRelay

**Рабочий стол — на том экране, которым вы пользуетесь.**

Включили Samsung → работает только телевизор. Выключили → только монитор. Приложения остаются открытыми, сохранённые разрешения и частоты возвращаются.

[English](README.md) · [Архитектура](docs/ARCHITECTURE.md) · [Правила для AI-агентов](AGENTS.md)

## Что внутри

Небольшой самостоятельный EXE для Windows 11 x64. Без PowerShell, установленного .NET, облака, аккаунта и телеметрии. В фоне нет консоли, окна и значка в трее.

ТВ опрашивается **раз в 0,5 секунды**, один запрос одновременно. Общий срок ответа — **200 мс**. Два ответа `on` переключают на ТВ; явный `off` или два пропущенных ответа — на монитор. При неправильной модели или некорректных данных автоматика приостанавливается.

## Настройка

1. Скачайте ZIP из [Releases](https://github.com/prodzaha/screenrelay/releases), распакуйте в постоянную папку. Откройте `ScreenRelay.exe --settings`.
2. Включите Samsung, введите его локальный IP и нажмите **Test TV**. Желательно закрепить адрес ТВ в DHCP роутера.
3. Нажмите **Win+P → Расширить**. В Windows выставьте нужные разрешения и частоты обоих экранов.
4. Выберите монитор и телевизор. Нажмите **Capture current Extended profiles** и подтвердите картинку в обоих одиночных тестах. Без подтверждения через 30 секунд вернётся предыдущая конфигурация.
5. Выберите автозапуск и клавиши. Нажмите **Save and start automation**.

Нужен совместимый локальный API Samsung на порту 8001 и частный IPv4-адрес. Поддержка всех моделей Samsung не заявляется.

## Управление

| Клавиши по умолчанию | Действие |
|---|---|
| Ctrl+Alt+F10 | Оба экрана |
| Ctrl+Alt+F11 | Только монитор |
| Ctrl+Alt+F9 | Только ТВ, если он подтвердил включение |

Ручной выбор сохраняется до следующего подтверждённого включения или выключения ТВ; опрос продолжается. Если начальное состояние неизвестно, первый устойчивый ответ задаёт исходное состояние и не отменяет ручной выбор. Команда `ScreenRelay.exe --auto` отменяет ручной выбор и сразу возвращает обычную автоматику. Клавиши меняются в настройках; занятые сочетания не перехватываются. Windows резервирует F12 для отладки: если она недоступна, выберите другую функциональную клавишу.

Чтобы изменить частоты, выставьте их в Windows и сохраните профили заново. Произвольные макросы, редактор правил и конфигурации более чем с двумя экранами сейчас отсутствуют.

## Ограничения без обещаний

- Выключенный Samsung может оставаться подключённым по HDMI. Поэтому используется сеть: два пропуска ответа считаются выключением. Сбой Wi-Fi тоже может вернуть вывод на монитор. Интернет не нужен.
- Ориентир переключения — 1–2 секунды после доступного сетевого ответа. Пробуждение ТВ и обработка Windows могут добавить время.
- Полноэкранная игра может потребовать повторного выбора экрана. Для такого сценария обычно удобнее оконный режим без рамки.
- После ошибки автоматика приостанавливается. Причина доступна в настройках и локальном журнале.

## Защита и нагрузка

Профиль проверяется до применения, затем сверяются экран, разрешение, частота и положение. Произвольное снижение частоты не разрешено. Отдельный короткоживущий процесс обеспечивает возврат, если переключение не подтверждено за 10 секунд.

После запуска и сна текущие идентификаторы GPU и экранов сопоставляются заново. При неоднозначности программа не угадывает цель. Драйверы, EDID, HDR/VRR, TDR и роутер не меняются.

Цель — менее 20 МиБ рабочего набора памяти и 0,1% средней загрузки всего CPU в покое. Это цели измерений, не гарантия. Результаты проверок и ограничения испытаний — в [VALIDATION.md](docs/VALIDATION.md).

Настройки и ограниченные журналы: `%LOCALAPPDATA%\ScreenRelay`. В них есть личные сведения об устройствах — не публикуйте эту папку. `--diagnose` создаёт отчёт без IP, UUID и путей видеокарты.

## Удаление

Выполните `--startup-off`, затем `--both` и `--exit`. Удалите программу и, при желании, локальные настройки. Автозапуск работает от текущего пользователя без администратора.

Начните с [AGENTS.md](AGENTS.md): там описаны логика, границы версии и обязательные проверки. Настройка устройств не требует изменения кода. Новые сценарии добавляйте отдельно, сохраняя защиту от неверного экрана и потери картинки.

Больше экранов, правила, макросы и другие ТВ — идеи на будущее, а не функции этой версии. Исходники открыты под MIT; проект независим от Microsoft и Samsung.
